# Tempest — a Porta plugin

Porta's built-in syntax highlighting engine, from tempest/highlight.

This is `janalis/porta-tempest`, one of the plugins bundled with
[Porta](https://github.com/janalis/porta), the terminal IDE for PHP. Porta
ships it already: turn it on under **Settings → Plugins**. Install this
package only to run a copy of your own, which shadows the bundled one.

- [Documentation](https://janalis.github.io/porta/plugins/tempest/)
- [Writing a plugin](https://janalis.github.io/porta/plugins)

## Read-only

This repository is a read-only split of `plugins/tempest` in
[janalis/porta](https://github.com/janalis/porta), updated on every push.
Report issues and send pull requests
[there](https://github.com/janalis/porta).
